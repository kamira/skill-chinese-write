## 這一輪最值得記的兩件事

**一、同一個詞,兩種文體判定相反。**

「予以」「加以」在 `writing` 與 `techdoc` 是**被架空的動詞**,要改掉;在公文裡它們是**精準的行文動詞**,不改。所以 `bizdoc` 刻意不沿用那兩支的弱動詞表。

這件事的價值超過這支 skill 本身:它是「四支 skill 至今不抽共用規則層」的具體證據。看起來重複的詞表,語意其實相反——抽成共用層會讓兩邊都不準,而且錯的方式很隱蔽(不是報錯,是判反)。KN-003 的觀察區記的正是這件事,本張把它從猜測變成實例。

**二、「斷言沒有夾具」又出現一次,而且這次是我自己先寫進約束再自己違反。**

CHG-20260810-06 的 Global Constraints 第三條白紙黑字寫著「每一條斷言都要有夾具會踩到」。寫完之後清點,三條沒有:主旨過長、主旨缺公文動詞、成語密度。

成語密度那條最值得看:它不是漏寫,是**卡在門檻上**——6 次 / 上限 6,而判斷式是 `> hi`,所以 6.0 不觸發。夾具「幾乎」踩到,報表看起來也正常,但那條斷言從未被證明會響。門檻型的斷言要用**超過**門檻的夾具去踩,不是剛好等於。

## 代使用者做的決定(請覆核)

1. **三段法只有主旨列硬性**,說明與辦法不強制——簡單通知只有主旨是合法的,三段全列必要會逼人寫空段落。
2. **導語的 5W 降級為「有沒有數字或日期」**,且列警告不列硬性。
3. **不禁第一人稱「我」。** 公文實務用「本府」「本局」,但 `chinese.md` 未言明,**原文沒寫的規則不自己發明**。
4. **企劃書未涵蓋。** 原文把「公文、一般企劃、新聞稿」列為同一類,但企劃書的結構規範原文沒給,只有「規格化與標準化」一句。已在 `docs/genres.md` 註明。

## 誠實的邊界

1. **驗收者與實作者是同一個。**
2. **成語表只有 18 條**,涵蓋概括災情與事件規模那一類,遠非完整;密度因此是低估。
3. **主旨偵測認三種寫法**(`主旨:`、`主 旨:`、`【主旨】`),但只有第一種有夾具踩到——另兩種靠 regex 讀,未實測。
4. **公文格式階層(一、(一)1.)只看得出有沒有編號,看不出用得對不對。**
5. **致意用語得不得體判不了**,那是關係判斷。
