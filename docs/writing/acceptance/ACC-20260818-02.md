## 殘留風險

- **首段直接謊寫「已驗收」的，任何內容閘都判不了。** 本閘治的是模板狀態忘了改，
  不是蓄意造假——這句寫進了 docstring，不是留白。
- baseline 是 16 筆具名檔名。它只能縮不能長（斷言 3 讓每筆自帶失效期），
  但加新條目仍只是閘檔的可見 diff，信任模型與 `EXPECT_UNVERIFIED` 相同。
- 圍籬濾法採「遇到 ``` 或 ~~~ 就翻轉狀態」。**不成對的圍籬會讓其後全部被視為圍籬內**，
  於是判成 `NO_STATUS` → 紅。方向是 fail-closed，但紅的理由會誤導。
