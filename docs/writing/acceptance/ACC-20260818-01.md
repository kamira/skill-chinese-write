### 被轉換的量

```
baixiang   資產宣稱 80170 bytes  sha ac69996f…
           git blob 80170 bytes  sha ac69996f…   CRLF 0       ← repo 內容一直是對的
           工作樹   83739 bytes  sha d9f0989c…   CRLF 3569
cilin      27665 → 28025(+360 個 CRLF)
```

**壞的是簽出,不是內容。** 這一點決定了修法:不是改資產,是禁止轉換。

## 條件 2:第 6 條的紅端在 Linux 上可達

第 1 條(sha256)的紅端**只在 Windows 可達**,而 CI runner 是 Linux——
所以它在 CI 上從未被測過(KN-001)。第 6 條把「設定有沒有寫」變成平台無關的斷言:

```
$ python skills/ci-poetry/scripts/assets_verify.py --self-test
✅ self-test:10 案全過
   綠 真實資產
   紅 .gitattributes 沒釘 vendored raw          ← 注入 "*.sh text eol=lf"
   綠 釘了就過                                   ← 注入 "*.wikitext -text"
   紅 規則被註解掉                               ← 注入 "# *.wikitext -text"
   邊界 不在 git 工作樹時第 6 條不成立(非靜默通過)
   紅 非 CJK 污染(ASCII)
   邊界 第 5 條抓不到簡化字,但第 4 條抓得到
   紅 tokens 自稱與實算不符
   紅 啟用了不對齊的牌
   紅 raw 被抽掉一行(符號守恆)
```

「註解掉」那一案是刻意的:`#` 之後若不剝掉,一行被註解的規則會被當成生效。

## 條件 3:「不在 git 工作樹」不是靜默通過

已安裝的 plugin 副本沒有 `.git`,第 6 條**不成立**而非通過——它防的是 git 簽出時的
轉換,**沒有 git 就沒有那個轉換**,條件本身不存在。

而這條路徑本身也被釘住,理由是:若 `_repo_root()` 哪天壞掉退回 `None`,
整條規則會在 repo 裡**靜默消失而 self-test 全綠**。self-test 因此斷言
本檔在 repo 內必須找得到 git 工作樹。
