## 這一輪最值得記的一件事

**改動前的 CI 也是全綠的。**

兩個目錄被 git 追蹤、與單一真相分岔 11 個檔、其中一份夾具用的是 zh-style 判為硬性違規的半形標點——而 13 道閘一道都沒響。原因不是任何一道閘壞掉,是它們**全部朝同一個方向走**:

| 閘 | 方向 |
|----|------|
| `catalog_check --check` | marketplace 名冊 → 磁碟 |
| `build_suite --check` | `PLUGINS` → plugin 內複本 |
| `skill_inventory_check` 第 2 項 | `PLUGINS` → `skills/` |

三道閘,三個起點,全部是**從名冊出發**。所以「沒被登記在名冊上」這件事本身,對它們是不可見的——不是判定錯,是根本走不到。

這與 CHG-20260810-07 的「規則管三處、斷言只查兩處」是同族,但更難察覺:那次至少有一份名冊列著第三處,對照就看得出來;這次**沒有任何一份文件說過 `plugins/` 底下應該有幾個目錄**,所以連可以對照的東西都不存在。

寫進 KN-001 的第五問是:凡是「A 的每一項都要在 B 裡」的斷言,都要回頭問一次「**B 裡有沒有 A 沒登記的**」。

## 誠實的邊界

1. **驗收者與實作者是同一個,且未經審議席複審——這在 rebase 之後成為 DIR-002 的不合規項。**

   本張的施工與驗收發生在 `main` 為 46331e8 時,那時 DIR-002 還在 `claude/fixture-cross-review` 上,本分支讀不到它。使用者其後指示「先合 fixture-cross-review,再把這支 rebase 上去」,合併後 DIR-002 生效,而本張現在**疊在它上面**。

   兩件事要分開記:

   - **本張的 ACC 沒有送 codex + fable 互審**,依 DIR-002 第 1 條,不得記為互審通過。**待補**——覆核範圍是「刪除而非納管」這個判斷與新斷言的三向相等邏輯,不必重審全部。
   - **merge 與 rebase 是不可逆動作,依 DIR-002 第 2 條主 agent 不得單方執行。**本次由**使用者直接指示**,不是主 agent 的判斷——DIR-002 管的是判定權從主 agent 往審議席移交,不是使用者自己的決定。這一項記為**依使用者指示執行**,不是單方裁決。

   另,孤兒事實本身是**使用者**在提問時直接指出的,我做的是查證與執行,不是發現。
2. **「刪除而非納管」的依據是 repo 自己寫下的判準**(兩份 SKILL.md 的引擎自述、zh-style 作為第三支引擎沒有 plugin 目錄的先例、KN-003 的觸發面判準),不是我另立的標準。若日後決定要把引擎也上架,推翻的是 KN-003,不是本張。
3. **`catalog_check --since` 在 commit 之前驗不到本張。**它比對的是 `origin/main..HEAD` 的 git diff,工作區的未提交變動不在範圍內——所以「刪檔要 bump」這一項,是先主動 bump、再於 commit 後複驗,不是被閘逼出來的。
4. **新斷言擋不住「登記了但內容是空的」。**三向相等只查名字,不查目錄裡有什麼。一個空的 `plugins/foo/` 只要同時寫進 `PLUGINS` 與 marketplace 就會過——那一層由 `catalog_check` 的 plugin.json 存在性接手,但兩者之間仍有縫。
5. **編號錯開是對的,但只擋掉了撞號,沒擋掉版號衝突。**本張取 -02 以避開 `claude/fixture-cross-review` 的 -01,rebase 時 CHG / ACC 兩檔確實零衝突;但 `marketplace.json` 的 `metadata.version` 仍然撞了(兩支各自從 2.2.0 往上 bump)。**檔名錯開不等於內容錯開**——凡是「單一計數器」型的欄位,平行分支都會撞,靠命名規則躲不掉。這次靠 `--bump` 對 base 重推導解決,而那正是 `catalog_check` docstring 早就寫過的理由:「人挑版號會對著一個會過期的基底」。

## 結論

**通過(單方,未經審議席複審)。** 9 條查核全數通過,rebase 後全部重跑一次。刪除的 23 個檔在 git 歷史裡完整可還原,而新斷言讓同一種孤兒下次在 CI 直接轉紅——先對真實輸入證明紅燈可達,才動手刪。

依 DIR-002,**本張不得記為互審通過**;待覆核項見「誠實的邊界」第 1 條。
