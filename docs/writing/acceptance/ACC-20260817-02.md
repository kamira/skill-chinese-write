## 3b：母體換過一次，理由在看結果前就成立

### 為什麼換

原母體 `chinese-poetry/chinese-poetry` 的 `宋词`（21,050 首，22 分片全數取得）**是簡體**，
而引擎的詞林正韻資產是繁體：

```
$ 對全語料字頻與 cilin.json 字集取交集
語料字次 1,412,746   相異字 5,976
在詞林表內：字次 935,157 (66.2%)   相異 3,047 (51.0%)
最常見的表外字：风×12861 无×8146 云×7586 来×7562 时×6386 处×5602 归×5167 …
```

**前 20 名表外字全是簡化字。** 直接跑量到的是字體差異，不是引擎對錯。
而簡→繁是一對多（`发`→發/髮、`云`→雲/云、`干`→乾/幹/干），**韻部隨選字而變**，
選錯會製造無法歸因的紅——與 `CHG-20260817-01` 條件三判定「分揀工不可估」同形。

codex 裁「**A：換繁體母體；找不到合格母體則轉 D（記死因）**」，並訂五條合格條件。

### 新母體與它滿足的條件

**宋詞三百首**（朱孝臧編，1924；`zh.wikisource.org/wiki/宋詞三百首?action=raw`，公有領域）

| codex 的條件 | 滿足方式 |
|---|---|

| 來源、版本、授權、取得方式可重現 | `sha256 70af025623a37b84fc3d5401c2833bd26f110cfbdfad7772f418d82b49da2216` |

| 覆蓋稽核後全樣本完成判定 | 282/282，見下 |

### 凍結的選樣規則（跑之前固定）

1. 篇目 = 每個 `=='''…'''（作者）==` 標頭 + 其後**第一個** `<poem>` 區塊
2. 牌名 = 粗體標題中 `·` 之前的部分
3. 正文 = `<poem>` 內容，剝全形空白（片界標記）與換行
4. **不去重** —— 重出照計並回報
5. **不校異文** —— 依來源原樣
6. **全收不挑** —— 每篇都要有判定或具名的未判定

### 守恆帳

```
raw 獨立計數：粗體標頭 283、<poem> 區塊 282
parse 命中 282 + 無 <poem> 的孤兒標頭 1（'元夕'）= 283 ✅
重出 18 組（不去重，照計）
全樣本完成判定 282/282，無靜默未驗
```

**第一版 parser 靜默漏掉 91 篇**——標頭與 `<poem>` 之間常有小序行（`（丙辰中秋…）`），
我的 regex 要求緊鄰。被丟掉的包含蘇軾〈水調歌頭〉，正好是啟用牌。

而我的守恆斷言 `assert sum(res) == n` 對的是**自己 parse 出來的數**——
**恆真，看不見漏掉的 91 篇**。改成對 raw 的標頭數才看得見。
這是本輪第四次踩到「檢查跑在丟失的下游」。

### 結果

```
落在九個啟用牌 31 篇：綠 26 / 紅 5 = 83.9%
逐牌：蝶戀花11、清平樂5、菩薩蠻4、念奴嬌4、虞美人3、卜算子3、水調歌頭1
零耦合：31 篇無一首等於白香譜例（獨立驗證，不是自我驗證）
```

**第一次跑是 21 綠 / 10 紅 = 67.7%**，而 10 紅裡有 5 首紅在句數／字數——
那正是 SKILL.md 明文列為「不判」的**同牌異體**。**引擎的行為與自己的宣稱衝突。**

codex 裁「**A：句數／字數不符改列未判定，不得判紅**」。改後 26 綠 / 5 紅。

**這不是為了讓數字好看而放寬**：判準是「宣稱不判的東西就不能判紅」，
與通過率無關；而收窄的方向由宣稱決定，不是由結果決定。

### 5 首殘餘，逐首具名成因

| 篇 | 成因 | 逐字證據 |
|---|---|---|
| 〈虞美人〉舒亶 | 平仄 | 第 8 句第 3 字「江」譜為 `●`，實為平 |
| 〈菩薩蠻〉陳克 | 平仄 | 第 4 句第 3 字「自」譜為 `○`，實為上去 |
| 〈蝶戀花〉周邦彥 | 平仄 | 第 5 句第 7 字「泠」譜為 `▲`，實為平 |
| 〈虞美人〉葉夢得 | 平仄 | 第 4 句第 3 字「游」、第 8 句第 3 字「多」，譜為 `●` 實為平 |
| 〈念奴嬌〉張孝祥 | 平仄 + 韻組 | 「無」`●`實平、「點」`○`實上去、「一」`○`實入、「處」`○`實上去 |

**沒有一首是「表錯」。** 五首全部指向同一件事：
白香在這些位置標了 `○`／`●`，而傳世作品實際是相反聲——**譜的 `⊙` 標得比實際格律嚴**。

codex 裁「**先量再訂**：暫維持紅並具名記錄，不因 5 例直接放寬；
用更大樣本量化各譜位的反例率，再決定哪些 `○/●` 應收窄或改為 `⊙`。」
立為 `BL-027`。
