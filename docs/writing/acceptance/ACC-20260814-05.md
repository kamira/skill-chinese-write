## 審議席抓到而我沒抓到的

**這一張裡,兩個最重要的發現都不是我找的。**

### 一、誠實欄是一場關鍵字賓果(F1,fable)

`[C]` 初版把整份文件當一個判定單元,只要求兩個語義成分「出現在文件裡」。
fable 用合成 probe **兩個方向都打穿**:

| 造假方向 | 舊實作 | 為什麼 |
|---|---|---|
| 成語列正面說謊「上限與下限都會擋」 | **綠燈** | 第二成分被*修辭列*的「沒有程式量得出」跨列滿足 |
| 修辭列說謊「lint 會量」 | **綠燈,而且誤掛一條下限的罪名** | 被*成語列*的「靠人判斷」跨列滿足 |

還有一條更難堪的:第二成分的 regex 寫成 `不(?:會|被)?(?:檢查|…)`,
**配不上「不會被檢查」**——`(?:會|被)?` 只吃得下一個字。而閘自己的綠端範例
用的正是那個措辭。**綠端一直是靠跨列污染成立的**;案 9 會紅也只是因為替換
順帶刪掉了「下限」二字,不是因為抓到謊。

**我寫的閘,犯了它自己要抓的病:規則寫逐項,斷言查整體。** 那是 KN-001。

修法:切判定單元(表格列各自獨立、其餘依空行分段),兩成分必須落在同一單元;
修 regex;補兩個紅端案,各自附「**不得誤掛罪名**」的反向斷言——抓錯人和沒抓到一樣壞。

### 二、freeform 的成員是 8 不是 9(fable 推翻審議席自己)

## 分歧與解決:六個宿主 plugin 要不要 bump

我在寫本份時量到 fiction 版號 bump 後,六個子流派 plugin 內含的 `fiction` SKILL.md
副本也跟著變了,而那六個 plugin 自己的版號沒動。我把它報成「A(a) 的同一個病」。

**兩席一度分歧:**

| 席 | 裁決 |
|---|---|
| codex(初) | **merge-blocking**,六支全部 bump 到 1.1.0(選 a) |
| fable | **不是 merge-blocking**,選 (c) 解耦 |

**fable 量到我漏量的維度**,我親自複驗:

```
$ git diff origin/main...HEAD --stat -- 'plugins/fiction-*/skills/fiction/SKILL.md'
 6 files changed, 6 insertions(+), 6 deletions(-)      ← 每檔 2 行

$ git diff origin/main...HEAD -- plugins/fiction-flash/skills/fiction/SKILL.md

-  version: 1.0.0
+  version: 1.1.0

$ git diff origin/main...HEAD --stat -- skills/fiction/SKILL.md
 1 file changed, 1 insertion(+), 1 deletion(-)         ← 源頭本身也只改版號行
```

**fiction skill 的規則內容一個字都沒動。** 所以:

- A(a) 是「**行為變了、版號沒動**」——使用者漏接實質變更,那是真傷害
- 本次是「**版號戳記變了、行為沒動**」——fiction-flash 1.0.0 的舊安裝與新安裝,
  skill 行為逐位元組等價

**我又把問題問錯了。** 我說「出貨內容變了」,卻沒量那個 delta 的內容是什麼。
本張第 3 次同型。

codex 收到複驗後**明確改判**:「在已核實 delta 僅為版號戳記、skill 行為逐位元組
等價的前提下,PR #15 不構成 merge blocker,維持放行。」

**為什麼不選 (a)**:bump 六個宿主會經同一條三處同步斷言,強迫
`skills/fiction-flash/SKILL.md` 的戳記也跟動,產出六個 release note 只能寫
「內含戳記變了」的空版本——**正是 `CHG-20260814-03` 剛擋掉的「無內容版本污染歷史」**。

## 我在本張裡犯的錯(KN-004 第 3、4、5 次)

1. **探針把統計行當違規行。** 引擎每次都印「成語 N 次(X/千字)」的統計,
   而我用 `"成語" in blob` 判定違規——於是超標稿與零成語稿都「命中」,
   上限被改成天文數字也照樣綠燈。**探針自己的假陽性,和它要抓的病同型。**
2. **方向詞猜成「超過」,引擎的用字是「高於」。** 那個字面是我從亂碼終端機的
   輸出裡猜的,不是量出來的,於是探針對真引擎恆為假陰性。
3. **誠實欄檔數報 1,實際 2。** 那是同步之前跑的數字。
4. **把六個副本的變動報成「出貨內容變了」,沒量 delta 的內容。** 實際只有版號行。

四次同源:**用回憶代替量測**。第 2 次讓 KN-004 的適用範圍從「凡數量、檔數、案數」
擴到「**凡寫進斷言的字面值——數字、訊息字串、路徑、旗標名**」;
第 4 次再補一句:**凡宣稱「變了」,必須附那個 delta 的內容,不只附它的檔名。**

## 閘擋下了我自己,而我改的是文案

`[C]` 改嚴之後,`commands/fiction-long.md` 立刻被自己的閘擋下:
那段解釋文字裡**引用了舊的錯誤寫法當反例**,引號裡含著一個成語區間。

修法是把引用改成示意寫法(`X-Y 次/千字`),**不是給閘加一條「引號內豁免」**
——那會變成「寫在引號裡就不必誠實」的後門。codex 的原話:
「引號不代表內容沒有規範效果;加入通用豁免會製造可繞過閘門的盲區。」

`ACC-20260814-03` 已經記過這條線:**驗收基準是拿來被滿足的,不是拿來被改到能滿足的。**
