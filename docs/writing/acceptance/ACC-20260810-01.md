## 這一輪最值得記的一件事

使用者最初的指示是「不需要 full-ci」,照字面做就是去砍 workflow 的步驟。**那會是個無效解**:
私有 repo 的 Actions 被帳務擋住時,擋的是 job 的**啟動**,不是某一步;workflow 砍到剩一行照樣紅。

差別在於有沒有去讀那行錯誤訊息。`The job was not started because recent account payments have failed`
這句話裡沒有任何一個字提到步驟。照字面執行會產生一個看起來有做事、實際上 PR 依然卡住的結果——
而且還順手拆掉了一道原本好好的閘。

## 誠實的邊界

1. **驗收者與實作者是同一個。** 中風險原則上要獨立驗收(verifier ≠ implementer),本輪 session
   沒有第二個驗收者,ACC 如實記下,不假裝滿足。
2. **hook 沒辦法自動生效。** `core.hooksPath` 不隨 clone 帶過來,沒跑過 `scripts/install-hooks.sh`
   的機器 push 時沒有任何閘。真正擋在 merge 前的是 autopilot runner 的 local-gate。
3. **轉 public 不可逆,且已執行。** 這一項沒有回滾路徑可驗——改回 private 救不回已被抓取的內容。
   能驗的只有「執行前有沒有真的看過內容」,那就是上面那張普查表的全部意義。
