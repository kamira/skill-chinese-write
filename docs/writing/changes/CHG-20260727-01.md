## 修改指引

### 目標

`writing` skill v1.0.0 上架:評論文體可用、小說/散文明確標未實作;五條下限全數有機器斷言;plugin 複本與 catalog 版本一致;CI 有迴歸夾具。

### Global Constraints(全域約束——每個 task 都要遵守)

- 版本三處同步:SKILL.md metadata、plugin.json、marketplace entry 皆 1.0.0;catalog metadata.version 必 bump
- 既有 skill(ai-sdlc / ai-sdlc-autopilot / intel-analysis)一字不動
