# zh-style — 中文正字法與收尾

> **這是引擎,不是前門。**它沒有自己的 plugin,由所有 plugin 打包帶入。

## 為什麼是共用的

其他引擎管的是文體:`writing` 要第一人稱,`fiction` 不要;`bizdoc` 要公文腔,`writing` 禁它。那些規則**隨文體改變**,所以各自一份。

這兩條不會:

| 規則 | 在散文 | 在公文 | 在規格書 |
|------|--------|--------|----------|
| 半形標點 | 錯 | 錯 | 錯 |
| 替讀者總結 | 不該 | 不該 | 不該 |

判定完全相同,複製四份必然分岔(KN-003:規則不隨文體改變就放共用引擎)。

## 一、半形標點(硬性違規)

中文脈絡下的 `,` `:` `;` `?` `!` `(` `)` 一律改全形。

**只在中文字元相鄰時判違規**。以下一律先遮蔽,因為半形在那裡是正確的:

- 程式碼區塊(```)與行內程式碼(`)
- markdown 連結語法 `[文字](網址)`
- URL
- 純英文與數字之間的標點(`3.2`、`hello, world`)

## 二、收尾(警告)

### 總結殼

最後一段出現這些形狀就提醒:「有些X是這樣」「不是A,是B」(收尾處)、「說到底」「其實一直」「歸根究柢」「X是有代價的」「而那正是」「真正⋯的是」。

它們的共同動作是**替讀者把意思講出來**。改法:換成具體的動作或事實,結論留給讀者自己得。

### 兩句光禿的短陳述並排

最後一段的末兩句都在 14 字以內、第二句既沒有連接詞開頭也沒有逗號停頓時提醒。

> 鐵門又響了一次。她沒有回頭。 → 鐵門又響了一次。這回,她沒有回頭。

差別有兩層:「這回,」給了時間錨點,把這一刻接回前面那一次;逗號也讓重音落在後半句,兩個事實因此接得起來,而不是並排放著。

## 三條靠你自己判斷(lint 判不了,明說)

1. **這個結尾有沒有在總結全文。** 本檔判的是**殼的形狀**,不是語意。一段沒有用任何殼、卻仍然在替讀者下結論的結尾,它抓不到。
2. **哪一句是反轉。**「母親走了十四年。」是揭曉,靠光禿地落地才有力道;加連接詞會把揭曉變成解釋。判不出來,所以那條只列**警告**——警告可以無視,硬性不行。
3. **開頭該不該也套這條。** 開頭要冷(把讀者丟進場景),結尾要重。本檔只看最後一段,取窄的一邊。

## 跑法

```
python3 skills/zh-style/scripts/zh_style_check.py 稿件.md
python3 skills/zh-style/scripts/zh_style_check.py --self-test
```
