# lyric — 抒情文 / 心得文

## 核心

以主觀情感為核心,或由外在媒介(書、影、事)引發個人反省、體悟與收穫。

**修辭比例**:中至高(20%-60%)

## 怎麼寫

**託物言志**、**呼告**、**層遞**、**感嘆**。

手法上:直抒胸臆、感發與聯想、類比常理、前後呼應。

## 成語運用

中(10%-20%)。

兩個情境:① **情感爆發**(情緒累積到頂點,需要一個重音符號來做結論);② **痛定思痛**(經歷某事後的深刻反省)。

落腳:【抒情高潮段】與【文末總結體悟段】。

## ⚠ 本支沒有 lint,規則靠人判斷

修辭比例的區間是 20%-60%——**橫跨 40 個百分點,本身就不是一個門檻**。一個從 20 到 60 都算合格的指標,設成斷言只會永遠是綠的。

上面每一條都是**寫作時的手感校準,不是斷言**。沒有任何程式在檢查它們,也不打算假裝有——寫成規則的樣子、放在規則文件裡、卻沒有人會執行,那種規則比沒有更糟,因為它讓文件看起來完整。

要判斷寫得好不好,只有一個辦法:自己讀一遍,問上面那幾條做到了沒有。

## 這個 repo 裡有 lint 的文體

評論(`writing`)、小說(`fiction` 與六支子層)、規格書與架構說明(`spec` / `architecture`)、公文與新聞稿(`official` / `press`)。各文體的狀態見 [`docs/genres.md`](../../docs/genres.md)。
