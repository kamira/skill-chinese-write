# fiction-romance — 言情 / 都市愛情小說

> 這是 **`fiction` 主層的子層**。主層管小說怎麼被讀進去(對話、分段、分章),本支管這個流派怎麼寫。

## 篇幅

不限篇幅

## 怎麼寫

以人物間的親密關係與情感糾葛為核心,著重**戀愛心理的細緻勾勒**與情感高潮渲染,常採男女主角**雙視角(POV)交替**。

大量使用細膩心理描寫、**營造氛圍的譬喻**(形容情感狀態)、**映襯**(愛恨 / 冷熱對比)。

這是唯一一個修辭密度高於武俠的流派——但方向不同:武俠的修辭往外(動作、氣勢),言情的修辭往內(心理、氛圍)。

## 兩個配比

| | 數值 | 誰在管 |
|---|---|---|
| **修辭比例** | 高(35%-45%),**全流派最高** | **靠人判斷**——沒有程式量得出一段文字有幾成是譬喻 |
| **成語密度** | 5-10 次/千字 | lint 會數(`--genre romance`),但區間是本 skill 自訂,不是原始規格的百分比 |

## 成語落在哪裡

① **情海生波**:誤會冰釋、生離死別或情感極度糾葛時。
② **內心小劇場**:曖昧期主角對一個眼神、一個動作的過度解讀與情緒放大。

**落腳段落**:落在大段的【人物內心獨白】與【情感爆發的哭戲 / 表白段】

## 主層的硬規範一樣要遵守

換人說話就獨立成段(同段最多兩處引號)、段落字數上限(實體 150 字 / 網文 80 字且不超過 3 行)、擬聲詞不用「X!」一聲的樣板、章節字數區間。細節見 `fiction` 的 [`references/dialogue.md`](../fiction/references/dialogue.md) 與 [`references/structure.md`](../fiction/references/structure.md)。

## 這個流派靠你自己判斷的

- **雙 POV 的兩個聲音分不分得出來**。程式看得出視角切換,看不出兩個人講話像不像同一個人。
- **情緒有沒有被賺到**。哭戲寫得夠不夠格讓讀者跟著哭,只有讀的人知道。
- **切章點**(斷頭台法則)。lint 量得出章有多長,量不出你停在哪一秒。

## 交稿前跑 lint

lint 在主層,本支不另外寫一份——武俠與科幻的規則檔會有 95% 相同,而重複的規則檔一定會分岔。安裝本 plugin 時主層會一起帶進來。

```
python3 skills/fiction/scripts/fiction_check.py 稿件.md --genre romance
```

網路連載加 `--mode web`(段落上限收緊為 80 字且不超過 3 行)。
