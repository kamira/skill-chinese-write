# writing

中文寫作技能(繁中)。目前只做一種文體:**評論文章**——時事評論、觀點文、專欄、影評書評、 產品/現象評論、讀後感式的論述。當使用者要寫評論、寫觀點、寫專欄、要你「針對某件事寫一篇 文章談看法」、要你把筆記或想法整理成一篇可讀的評論、或要你改稿讓文章不那麼像 AI 寫的時候 使用。核心約束:第一人稱、口語、句長刻意參差、對稱句只用在零星重點、禁 AI 腔與公文腔詞句。 議題型另有分節寫法(現象/可選的省思/結語/後記,要寫出感受)。 規則不是散文建議而是可跑的 lint(`scripts/style_check.py`;**只支援中文**)。也能接手改稿:使用者丟一篇已經寫好 的文章要你「去掉 AI 味」「改得像人寫的」「潤一下但不要變成公文」時,走改稿模式(保存優先—— 不編造、不換作者的判斷)。**小說請用 `fiction` skill**(它的硬規則與本 skill 相反);散文、詩歌、 劇本等其他文體尚未實作,不要冒充。

```
/plugin marketplace add kamira/skill-chinese-write
/plugin install writing
```

完整規範見 `skills/writing/SKILL.md`。各文體的拆分判準見 knowledge 的 KN-003。
