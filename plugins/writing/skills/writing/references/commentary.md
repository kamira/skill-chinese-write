# 評論文章:骨架

> 聲音與節奏看 [`voice.md`](voice.md);交稿前的清詞看 [`ai-tells.md`](ai-tells.md)。這份只管一件事——**一篇評論怎麼站起來**。

## 評論不是什麼

先把三個容易混進來的東西擋掉,不然寫出來的會是四不像:

- **不是報導**。報導的價值在「發生了什麼」,評論的價值在「所以呢」。如果整篇拿掉之後讀者只多知道了事實,那不是評論,是有形容詞的新聞。
- **不是心得**。心得是「我覺得很棒」,評論是「我覺得很棒,而且我能說出它為什麼棒、棒在哪個別人沒注意到的地方、以及這件事對誰重要」。差別在於有沒有承擔說服的責任。
- **不是論文**。論文要窮盡文獻、要留退路。評論可以偏,而且應該偏——你就是在講你的看法。但偏要偏得誠實:不迴避對你不利的事實,只是你認為它沒有推翻結論。

## 動筆前:先把主張縮成一句

寫之前,強迫自己把整篇的主張寫成**一句可以被人當面反駁的話**。

不合格的:「我認為遠端工作有優點也有缺點。」——沒人能反駁,因為它什麼都沒說。
不合格的:「遠端工作改變了現代職場。」——這是事實描述,不是主張。
合格的:「遠端工作真正殺死的不是通勤,是新人。公司省下的辦公室成本,是拿三年後沒人接得上手換來的。」

合格的主張有三個特徵:有人會不同意、講得夠具體所以能被證據打、而且講完之後你自己還想繼續往下說。

**這句話寫不出來,就還不能動筆。**這時候不要開始鋪陳背景拖時間——那是最典型的沒想清楚的症狀。回去想,或直接跟使用者說材料不夠、想問什麼。

## 開頭

開頭要做的事只有一件:**讓人願意讀第二段**。

能用的路數(不必四選一,能混):

- **直接把結論摔出來。**「我不相信這部片會得獎,而且我覺得它不該得。」然後整篇解釋為什麼。適合你的立場夠反直覺的時候。
- **從一個很小的具體場景進去。**一個畫面、一句對話、一個數字。小到讀者能看見,然後你從它拉出整件事。這招最好用,因為具體的東西自帶說服力。
- **先講一個大家都以為的事,再說我不這麼想。**製造落差。但別把前半段寫太長,兩三句就要翻。
- **從自己的困惑開始。**「我一直搞不懂一件事。」誠實的困惑比假裝的權威好讀。

開頭**不能**做的事:

- 不要交代背景。讀者不需要知道事情的來龍去脈才能讀你的第一句。背景要餵,邊走邊餵。
- 不要定義名詞。
- 不要寫「近年來,隨著⋯⋯的發展」。這句話等於在說「我還沒想到怎麼開頭」。
- 不要預告接下來要講什麼。評論不是簡報。

## 主張的形狀

一篇評論通常撐得起**一個**主張,加上兩到三個支撐它的次級論點。多了會散。

次級論點之間要有推進關係,不是並列關係。並列是:理由一、理由二、理由三。推進是:因為 A,所以本來以為 B,但 B 遇到 C 就垮了,於是真正的問題是 D。

判斷方法很簡單——**把第二段和第三段對調,如果讀起來沒差,那你在列點,不是在論證**。

## 證據給到哪

給到讀者不會問「真的嗎」就好,再多就變成堆料。

- 一個具體到有名字、有數字、有時間的例子,勝過三個模糊的例子。
- 數字要帶對照。「營收成長 30%」沒有意義,「營收成長 30%,同期同業平均是 4%」才有。
- 引用別人的話,要引到能反映對方原意的長度。斷章取義寫評論,讀者一查就完蛋,整篇的信用一起賠掉。
- **沒有的東西不要編**。不確定的數字就寫不確定,或者直接說「我手上沒有數字,但從 X 可以推得」。編造一個看起來很專業的統計是最快毀掉一篇評論的方式。

## 讓步要放在會痛的地方

大部分人寫讓步是這樣:整篇罵完,最後補一句「當然,凡事都有兩面」。這種讓步沒有作用,讀者一眼看穿是在買保險。

有效的讓步長這樣:**在你論證最脆弱的那一步,主動把最強的反駁講出來,然後回應它**。

比方你說遠端工作害了新人,最強的反駁是「以前坐在辦公室的新人也沒人帶,只是看起來有人在旁邊」。這個反駁很硬,你必須正面接:承認舊制度也爛,但爛的方式不同——以前是偶然沒學到,現在是結構上學不到,因為沒有旁聽的機會了。

讓步放對地方,文章會變強。放在結尾當免責聲明,只會變軟。

## 段落怎麼接

不要用「首先」「其次」「另一方面」「綜上所述」串。那是簡報的接法,不是文章的接法。

文章靠**內容本身**推進。上一段結束在一個判斷,下一段從那個判斷的漏洞或後果開始。讀者跟得上是因為邏輯連著,不是因為你貼了標籤。

如果你發現不貼標籤讀者就會迷路,那真正的問題是段落順序不對,不是缺標籤。

## 結尾

**不要總結。**讀者剛讀完,他記得。

結尾的作用是把整篇往前再推半步:一個延伸出去的問題、一個沒解決的矛盾、一個把視角拉遠的畫面、或是把開頭那個小場景再叫回來但意思已經變了。

**不要用一句短話收尾。**「帳要算全。」「數不出來。」這種四個字的收法看起來很有力,實際上是在擺姿勢——它把文章關起來,而讀者要的是還開著。lint 會擋:全文最後一句低於 **12 字**即硬性違規。

想收在一個短判斷的時候,有兩條路。把它併進前一句,讓它變成長句的後半;或者往後再走一層,講出那個判斷還沒解決的部分。

> ✗ ⋯⋯推到那個現在沒人教、以後也接不上手的位置上。省下的是租金,賠掉的是接班。
>
> 　帳要算全。
>
> ✓ ⋯⋯省下的是租金,賠掉的是接班。這筆帳今年不會出現在任何一張報表上,要等到那個新人該升上來、而他手上一次旁聽的記憶都沒有的時候,才會有人開始算。

另外一條:結尾不要向讀者討拍。「你覺得呢?」「是不是很有啟發?」這類點名讀者的問句同樣是硬性違規。不點名的反詰不受限——「這筆帳,最後誰在付?」是好收尾。

## 議題型:分節寫

上面講的是不分節的評論——靠論證一路推到底。**議題型**不一樣。當你寫的是一件正在發生、牽涉到別人處境的事(一項新規定、一種被普遍採用的做法、一個引起爭議的判決),用分節。

範例見 [`../assets/sample-issue.md`](../assets/sample-issue.md)。

### 三到四節

| 節 | 必要性 | 放什麼 |
|----|--------|--------|
| **現象** | 必要 | 簡短說明這件事是什麼,或者純粹描述現象、先不評論 |
| 反觀 / 省思 | **可選** | 你自己的觀察、實驗、經歷。有話講才留,沒有就三節 |
| **結語** | 必要 | 表態。這是收力,不是複述——講出前面沒出現過的判準 |
| **後記** | 必要 | 補述。把作者自己放進這件事裡:你的位置、你沒把握的地方、你的利益關係 |

「結語」跟前面說的「不要總結」不衝突。總結是把講過的話再講一次;結語是把立場講死,並且給出一個新的落點。

### 條列就要壓縮

用條列的理由只有一個:**省字**。寫成句子等於既佔了條列的版面,又沒有省到字。

實測的對照(左邊是 agent 寫的,右邊是使用者改的):

| 寫成句子 | 壓縮過 |
|---|---|
| 一餐的成本壓得下來(9 字) | 降低成本(4 字) |
| 食安稽核只要查一個點(10 字) | 單一稽核單位(6 字) |
| 學校不必再自己找廚工(10 字) | 校方不需廚工(6 字) |

左欄不是寫得不好,是**放錯位置**——那些話寫進段落裡完全沒問題,放進條列就變成
一個假的清單:看起來整齊,實際上讀者還是得逐句讀完。

**這一節沒有機器在管,而且是刻意的。** 我一度把 lint 上限收到 8 字,依據就是上面
那個對照——被使用者當場指出是**過度一般化**:不同文章的條列該多長不一樣,
一篇文章的合適值不是所有文章的規則。lint 現在只留 16 字的兜底,擋明顯過長的,
壓縮夠不夠靠自己讀。

自己讀的時候問一句:**這一項能不能再砍掉一半而不失去意思?** 能,就砍。

代價講明:因此 lint **抓不到**「一餐的成本壓得下來」這種寫成句子的條列。
這是刻意的取捨——為了不誤殺正確寫法而放棄一部分覆蓋率(KN-002)。

### 小標要有內容

`現象`、`結語`、`後記` 是功能名,直接用沒問題。但**可選的那一節不要叫「反觀」或「省思」**——那是結構標籤,等於什麼都沒說。換成具體的問題或判斷:

> ✗ ## 反觀
> ✓ ## 這篇真的是 AI 寫的嗎

### 要寫出感受

議題型不能只有事實跟判斷。你對這件事的反應要在裡面——但反應是**你的**,不是替事實加戲。

> ✗ 這是一個令人震驚的現象,其影響不容忽視。(形容詞在替論證做事)
> ✓ 我一開始覺得好笑,看到第三條就笑不出來了。(我的反應,而且有時間軸)

分界:寫你當下怎麼了(愣住、不舒服、笑不出來),不要寫這件事有多嚴重。嚴重不嚴重,讀者自己判斷。

### 現象節可以條列

這是唯一該用條列的地方——把這件事包含哪些東西列清楚。規則兩條:

- **只放扼要重點,禁止完整說明。**每項上限 16 字,完整解釋寫進段落
- 條列前後都要有散文,不能整節都是清單

> ✗ - 一個百分比,說整篇有多少比例被判為機器所寫
> ✓ - 一個百分比

## 常見敗筆

寫完對照一次:

- [ ] 主張能被反駁嗎?還是講了等於沒講
- [ ] 段落對調會不會沒差(=在列點不是在論證)
- [ ] 開頭有沒有在交代背景、定義名詞、預告結構
- [ ] 有沒有為了平衡而平衡,兩邊各打五十大板,最後沒有立場
- [ ] 形容詞是不是在替論證做事(「令人震驚的」「極其重要的」——刪掉,讓事實自己震驚)
- [ ] 有沒有反覆講同一件事,只是換了說法
- [ ] 結尾是不是在總結
- [ ] 拿掉署名,看得出是誰寫的嗎

## 長度

沒有標準長度,但有兩個實務門檻:短於 600 字通常來不及論證,只夠喊口號;長於 2500 字而只有一個主張,通常是在原地繞。

段落不要一樣長。連續三段都是五六行,讀者會累。中間丟一個兩行的短段落,節奏就回來了——這件事的細節在 [`voice.md`](voice.md)。
