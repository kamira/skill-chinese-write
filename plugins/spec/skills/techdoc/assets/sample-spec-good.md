# 匯出服務規格書 v1.0

## 1. 範圍

1.1 本規格定義匯出服務的功能需求、效能門檻與驗收標準。
1.2 本規格不涵蓋匯入流程,該部分見另一份文件。

## 2. 功能需求

2.1 匯出格式

- 2.1.1 服務必須支援 CSV 與 JSON 兩種輸出格式。
- 2.1.2 服務不得在未指定格式時預設輸出任何一種,必須回傳 400 與錯誤碼 `FORMAT_REQUIRED`。
- 2.1.3 CSV 的欄位分隔字元必須是逗號,換行必須是 LF。

2.2 資料範圍

- 2.2.1 單次匯出的列數上限為 100,000 列。
- 2.2.2 超過上限時,服務必須回傳 413 與錯誤碼 `RANGE_TOO_LARGE`,並在回應中帶上建議的切分區間。
- 2.2.3 匯出內容必須只包含呼叫者具備讀取權限的欄位。

## 3. 效能門檻

3.1 10,000 列的匯出必須在 3 秒內完成(P95,單一節點,4 vCPU / 8 GB)。
3.2 100,000 列的匯出必須在 30 秒內完成(P95,同上環境)。
3.3 併發 50 個匯出請求時,P99 延遲不得超過單請求延遲的 3 倍。

## 4. 錯誤處理

4.1 所有錯誤回應必須包含 `code`、`message`、`request_id` 三個欄位。
4.2 `request_id` 必須與存取日誌中的識別碼一致。
4.3 服務不可在錯誤訊息中回傳資料庫的原始錯誤字串。

## 5. 驗收標準

5.1 第 2 節每一條需求各有至少一個自動化測試,且測試在 CI 中執行。
5.2 第 3 節的三項門檻以壓測腳本驗證,結果留存於 `artifacts/perf/`。
5.3 第 4.3 條以注入資料庫錯誤的測試驗證,斷言回應中不含 `SQLSTATE`。
