# fu — 賦 / 駢文

## 核心

句式排比對仗(四六句為主),講究平仄聲律與辭藻華麗。

**修辭比例**:**極高(60%-80%)**

## 怎麼寫

**對偶**、**排比**(鋪陳)、**用典**、**誇張**。

手法上:鋪陳羅列、**事事用典**、聲律對仗。

## 成語運用

**最高(50%-70%)**,全部文體之冠。

情境:大規模鋪陳排比,用密集的典故與成語展現學識與氣勢。

落腳:【全篇所有排比與對偶段落】。

## ⚠ 本支沒有 lint,規則靠人判斷

這個文體與 `writing` 是**正面衝突**的最乾淨例子:`writing` 把字數對稱的句子列為配額制(全篇最多三處),而賦要的正是通篇對偶。

四六句與對偶的**字數對稱恰好可判**,所以這一支未來有機會有 lint——但那份規則檔會與 `writing` 的判定完全相反,必須是獨立的引擎。目前尚未建。

上面每一條都是**寫作時的手感校準,不是斷言**。沒有任何程式在檢查它們,也不打算假裝有——寫成規則的樣子、放在規則文件裡、卻沒有人會執行,那種規則比沒有更糟,因為它讓文件看起來完整。

要判斷寫得好不好,只有一個辦法:自己讀一遍,問上面那幾條做到了沒有。

## 這個 repo 裡有 lint 的文體

評論(`writing`)、小說(`fiction` 與六支子層)、規格書與架構說明(`spec` / `architecture`)、公文與新聞稿(`official` / `press`)。各文體的狀態見 [`docs/genres.md`](../../docs/genres.md)。
