# fiction — 中文小說

> 繁體中文。lint 只支援中文。這支 skill 管的是**小說怎麼被讀進去**:對話怎麼排、段落多長、章在哪裡切。

## 為什麼不是 writing 的一個模式

`writing` 管評論。它的三條硬規則對小說是**反的**:

| `writing` 的硬規則 | 小說 |
|--------------------|------|
| 全篇必須出現「我」 | 第三人稱限知是主流視角,沒有「我」完全正常 |
| 結尾句低於 12 字即違規 | 斷頭台法則要的就是「那保險箱裡竟然是⋯⋯」 |
| 刻意句(明喻/對稱/反差)全篇上限 3 處 | 武打段落要的就是密集對偶與誇張 |

所以是兩支 skill,不是一支的兩個旗標。要寫評論請用 `writing`。

## 三份規則,分工

| 檔案 | 管什麼 | 什麼時候讀 |
|------|--------|-----------|
| [`references/dialogue.md`](references/dialogue.md) | 對話三種形式、何時插入對話、擬聲詞的取代法 | 寫到有人開口時 |
| [`references/structure.md`](references/structure.md) | 分段、分行、分章;切章點;視覺切割 | 排版與收章時 |
| [`references/genres.md`](references/genres.md) | 篇幅與流派各自的寫法、修辭與成語配比 | 動筆前定調 |

## 四條硬規範

這四條是可判定的,lint 會擋:

1. **換人說話就獨立成段、獨立分行。** 同一段最多兩處引號——那是夾敘夾議式的「先開口、插入動作神態、再開口」。三處以上代表你把多輪對話擠進同一段了。
2. **段落有字數上限。** 實體出版 150 字;網路連載 80 字**且**不超過 3 行(手機閱讀)。用 `--mode web` 切換。
3. **擬聲詞不要用樣板。** 「轟隆!」一聲,天空打雷了 —— 這是低階寫法,lint 直接擋。改用強動詞:悶雷**滾過**天際,沉重地壓在屋頂上。
4. **擬聲詞能不用就不用。** 超過每千字 3 次會報警。滿篇「啪、轟、啊」是初學者的樣子。

## 四條靠你自己判斷(lint 判不了,明說)

寫成規則的樣子、放在規則文件裡、卻沒有人會執行——那種規則比沒有更糟。以下四條**沒有斷言**,靠你讀:

1. **黃金切章點(斷頭台法則)。** 在答案即將揭曉的前一秒停住。機器量得出章有多長,量不出你停在哪一秒。
2. **心理活動獨立成段。** 重大轉折或頓悟時單獨給它一行。什麼算重大,只有你知道。
3. **留白與伏筆。** 微型小說靠象徵與留白,懸疑靠資訊不對稱與紅鯡魚。這兩件事沒有任何程式看得出來。
4. **修辭比例。** `references/genres.md` 給了各流派的修辭比例區間(例如武俠 30%-40%),那是**寫作時的手感,不是斷言**——沒有程式量得出一段文字有幾成是譬喻。

成語密度是唯一一個被半機器化的:lint 會數,但區間是**本 skill 自訂**的「次數/千字」,不是原始規格的百分比(那個百分比沒有定義分母)。當參考,別當判決。

## 交稿前跑 lint

```
python3 skills/fiction/scripts/fiction_check.py 稿件.md --genre wuxia
```

流派可選 `wuxia` / `scifi` / `mystery` / `romance` / `flash` / `long`;不給就只報數不判定。網文加 `--mode web`。

它報四組:

1. **硬性違規** —— 段落過長、一段塞多輪對話、擬聲詞樣板 → **exit 1,回去改**
2. **對話** —— 純對話連續超過 4 段、無意義寒暄
3. **密度** —— 擬聲詞、成語
4. **架構** —— 章節字數區間

第 2 到 4 組只警告。要接進別的流程加 `--json`。

規則的單一真相在 [`assets/fiction_rules.json`](assets/fiction_rules.json)。要調門檻改那份,不要改腳本。

## lint 之後:自己問五件事

lint 擋得住「排版像新手」,擋不住「沒人想看下去」。過稿之後每項 1 到 10 分:

| 維度 | 問題 | 1 分 | 10 分 |
|------|------|------|-------|
| **推進** | 這一章有沒有讓事情往前走 | 全在描寫,狀態沒變 | 讀完之後局勢不一樣了 |
| **人物** | 對話有沒有洩漏這個人是誰 | 誰講都一樣 | 光看台詞就認得出是誰 |
| **具體** | 場景有沒有一個看得見的東西 | 全是抽象的氣氛 | 袖口那道舊疤 |
| **懸念** | 章尾有沒有讓人想點下一章 | 事情剛好收乾淨 | 停在還沒揭曉的前一秒 |
| **克制** | 有沒有把讀者猜得到的話講出來 | 每個動作都補一句心理解釋 | 動作講完就走 |

**低於 35 分就回去改。**

> 五維評分的形式改編自 `stephenturner/skill-deslop`(MIT),維度為本 skill 自訂。規範內容改編自使用者提供的 `chinese.md`,差異(修辭比例未實作、成語改自訂密度、對話輪數門檻放寬)見 plugin 的 `THIRD-PARTY-NOTICES.md`。
