# fiction-wuxia — 武俠 / 仙俠小說

> 這是 **`fiction` 主層的子層**。主層管小說怎麼被讀進去(對話、分段、分章),本支管這個流派怎麼寫。

## 篇幅

不限篇幅,但動作場面的密度是這個流派的核心

## 怎麼寫

以江湖恩怨、快意恩仇或修真歷練為主軸。講究**動作流暢感**、**招式畫面感**與**古風意境**。

大量使用**動態摹寫**(讓招式看得見軌跡)、**誇張**(形容功力)、**對偶**(功法與招式名)。

這是唯一一個「成語密集」不是缺點的流派——密集的四字結構本身就是節奏,武打段落靠它推速度。

## 兩個配比

| | 數值 | 誰在管 |
|---|---|---|
| **修辭比例** | 中高(30%-40%),全流派第二高 | **靠人判斷**——沒有程式量得出一段文字有幾成是譬喻 |
| **成語密度** | 8-14 次/千字,**全流派最高** | lint 會數(`--genre wuxia`),但區間是本 skill 自訂,不是原始規格的百分比 |

## 成語落在哪裡

① **武打交鋒**:雙方身法、內力碰撞的瞬間,需要強烈的畫面感與速度感。
② **兩雄對峙**:決鬥前的氣壓、眼神交鋒。

反過來說,文戲段落把成語降回中等密度——全篇一路密集會失去對比,武打就不再是高潮。

**落腳段落**:高度集中於【動作場面描寫段】與【招式對決高潮段】

## 主層的硬規範一樣要遵守

換人說話就獨立成段(同段最多兩處引號)、段落字數上限(實體 150 字 / 網文 80 字且不超過 3 行)、擬聲詞不用「X!」一聲的樣板、章節字數區間。細節見 `fiction` 的 [`references/dialogue.md`](../fiction/references/dialogue.md) 與 [`references/structure.md`](../fiction/references/structure.md)。

## 這個流派靠你自己判斷的

- **招式名取得好不好**。對偶結構程式看得出來,取得漂不漂亮看不出來。
- **古風意境**。用詞的年代感沒有詞表判得了,現代詞混進去只有讀的人會出戲。
- **切章點**(斷頭台法則)。lint 量得出章有多長,量不出你停在哪一秒。

## 交稿前跑 lint

lint 在主層,本支不另外寫一份——武俠與科幻的規則檔會有 95% 相同,而重複的規則檔一定會分岔。安裝本 plugin 時主層會一起帶進來。

```
python3 skills/fiction/scripts/fiction_check.py 稿件.md --genre wuxia
```

網路連載加 `--mode web`(段落上限收緊為 80 字且不超過 3 行)。
