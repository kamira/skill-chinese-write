# poetry — 詩歌

## 核心

分行跳躍,用凝練、具音樂性的語言表達強烈情感。

**修辭比例**:**最高(70%-90%)**

## 怎麼寫

**隱喻**、**擬物 / 擬人**、**錯置**(文法倒裝)、**呼告**。

手法上:意象跳躍、**打破常規語法**、韻律與音樂性的營造。

## 成語運用

極低(0%-5%)。詩歌追求意象的獨特與打破常規,成語容易顯得俗套。

唯一的用法是**刻意進行「成語拆解」或「反用成語」**,製造解構、新鮮感與諷刺效果。

落腳:詩眼的【核心轉折句】或【結尾重音句】。

## ⚠ 本支沒有 lint,規則靠人判斷

詩歌與 lint 的前提**直接衝突**:它的手法之一是「打破常規語法」,而 lint 的存在假設是「有常規可循」。

這不是暫時沒做,是這個文體本質上不適合被靜態檢查。本支只給寫作指引。

上面每一條都是**寫作時的手感校準,不是斷言**。沒有任何程式在檢查它們,也不打算假裝有——寫成規則的樣子、放在規則文件裡、卻沒有人會執行,那種規則比沒有更糟,因為它讓文件看起來完整。

要判斷寫得好不好,只有一個辦法:自己讀一遍,問上面那幾條做到了沒有。

## 這個 repo 裡有 lint 的文體

評論(`writing`)、小說(`fiction` 與六支子層)、規格書與架構說明(`spec` / `architecture`)、公文與新聞稿(`official` / `press`)。各文體的狀態見 [`docs/genres.md`](../../docs/genres.md)。
