# ci-poetry — 詞(宋詞)

## 核心

**詞是「填」不是「寫」。** 詞牌先於內容:句數、每句字數、韻位落在哪一句、
該押平韻還是仄韻,全部由詞牌決定。你選了〈菩薩蠻〉,就等於選了
「七七五五・五五五五、四換韻」這個模子。

押韻用**詞林正韻**(清・戈載,1821),不是平水韻,也不是現代國語。
它把平水韻 106 部併為 19 部,而**上去通押、入聲獨押** ——
這不是誰的學術主張,是戈載分部結構本身:第 1–14 部的仄聲節寫「上聲…去聲…」,
第 15–19 部的入聲**獨立成部、獨立標頭,無一例外**。

## 怎麼填

**先挑詞牌,再想內容。** 反過來做,寫到一半會發現句子塞不進模子。
本工具啟用九個常用牌:

```
菩薩蠻  虞美人  西江月  卜算子  蝶戀花
水調歌頭  清平樂  如夢令  念奴嬌
```

**換韻是詞牌規定的,不是自由。** 〈菩薩蠻〉四換韻,〈虞美人〉四換韻,
而〈蝶戀花〉一韻到底。換錯地方不是風格,是不合譜。

**⊙ 的位置才是你的自由。** 白香詞譜用 `○平 ●仄 ⊙可平可仄`,
其中 `⊙` 佔全部符號的兩成——**那是譜給的餘裕,不是模糊**。
`○●` 的位置沒有商量。

## 成語運用

詞**不用成語**,用典。詞的字數比近體詩更緊,四字現成語一放進去,
一句就去掉大半。真正的做法是把典壓成兩三個字,讓讀的人自己展開——
「廉頗老矣,尚能飯否」用了一整個典,而字面上一個成語都沒有。

## 跑 lint

```
python3 scripts/ci_check.py --tune 菩薩蠻 你的詞.md
```

判這些:

- **韻組**:按連續同符號 run 切(同符號再現另起新組),組內須同詞林部
- `○●` 位置的平仄,`⊙` 一律放行

**句數或字數對不上,輸出「未判定」而不是紅。** 白香每調只收一體,
欽定詞譜有 2304 體——對不上最可能是本工具未收的體,不是你寫錯。
3b 實測 31 篇名家詞的 10 紅裡,5 首正是這種:姜夔〈念奴嬌・鬧紅一舸〉逐句全不同、
李清照〈念奴嬌〉、辛棄疾 19 句、晏幾道〈虞美人〉10 句、李之儀〈卜算子〉第 8 句 6 字。
**把名家的合法變體判成錯,會教人整道閘一起忽略。**

### 稿件格式:標題請用 `#` 開頭

```markdown
# 詞牌名 — 作者

(詞文寫在這裡,標點照常打)
```

示例刻意不引真的詞:`[10b/19]` 這道閘擋的是「夾具引用規則自己的示範句」,
而我第一版在這裡引了 `sample-good.md` 的標題與首句,當場被擋——**同一個坑,第二次**。

`#` 標題、`>` 引言、`|` 表格、圍籬都會被剝掉;
`- ` `* ` 清單只去掉符號、**內容保留**,所以把詞寫成清單不會被誤判成空。

**唯一的已知限制**:無標點又沒有 `#` 的標題行(如 `清平樂・晚春`)
會被併進第一句,於是那句變成 9 字而報「疑為本工具未收之體」——**指在錯的地方**,
你會去看那句沒錯的首句。自動辨識它需要「首行短、含詞牌名」這類猜測,
而那會新增誤殺面,所以這裡用契約收口而不是用猜的。**加個 `#` 就好。**

## ⚠ 明標不判的部分

| 不判 | 為什麼 |
|---|---|
| **同牌異體** | 白香每調只收一體;欽定詞譜有 2304 體,本工具沒有那份資料 |
| **換韻的合法性** | 組間不比較——「這裡該不該換韻」需要譜的韻位語意,白香的符號不帶 |
| **通叶「平仄兩組須同部」** | 同上 |
| **領字、去聲位、片界** | 白香的空行不可靠對應片界,已明標不判 |
| **表外字** | 列「未判定」,**不當通過也不當違規** |

**未收之體不是違規。** 你填的若是白香沒收的體,輸出是
「非本工具所收白香體/未判定」——不是報錯,也不硬猜最近的牌。

## 名家範例也可能不合後世韻書

白香收的〈念奴嬌〉範例是**薩都剌〈登石頭城〉**(「石頭城上,望天低吳楚」),
而九個啟用牌的譜例裡,只有它不全綠,兩處都可具名:

```
韻組(▲)物壁雪傑發滅發月   壁屬第十七部、其餘七字屬第十八部
第 20 句第 3 字「一」        譜為 ○(平),而「一」是入聲
```

本工具對它輸出「**依詞林正韻無共同部**」,不寫「錯」。
詞林正韻成書於 1821 年,比薩都剌晚近五百年;**用後世的韻書量前代的作品,
量出來的是差異,不是錯誤**。

也因此驗收線**不訂「名家範例 100% 通過」**——那條線會逼人去改資料迎合引擎。
改訂:全樣本必須完成判定且無靜默未驗、每個不通過案例必須可重現並列出逐字部屬、
版本更新不得新增未解釋的退步。

## 這個 repo 裡有 lint 的文體

見 `docs/genres.md`。

**不要拿 `regulated-verse`(近體詩)套詞**:那支定句定字、押平水韻、判對句平仄相對;
詞依詞牌、押詞林正韻、韻位由譜給定。同理不要拿 `poetry`(現代詩)來量。
