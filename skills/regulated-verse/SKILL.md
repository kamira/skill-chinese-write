# regulated-verse — 近體詩(絕句・律詩)

## 核心

定句、定字、定韻、定平仄。四者缺一就不是近體詩。

| | 絕句 | 律詩 |
|---|---|---|
| 句數 | 4 | 8 |
| 每句 | 五言或七言,全篇一致 | 同左 |
| 韻腳 | 偶數句末,一韻到底 | 同左 |
| 對仗 | 不要求 | **頷聯(3-4)、頸聯(5-6)要求** |

押韻用**平水韻**,不是現代國語。這件事是整支 skill 的地基:

```
一 yī(一聲)、白 bái(二聲)、國 guó(二聲)  三個字都是入聲,屬仄
```

現代國語入聲已消失、派入四聲,所以**用國語聲調判平仄,對每一個入聲字都會判錯**。

## 怎麼寫

**先定體裁再下筆。** 五絕 20 字、七絕 28 字、五律 40 字、七律 56 字——
篇幅是先決條件,不是寫完才數。

**韻腳先選。** 一韻到底,中途換韻就不是近體詩。選韻部時看它的字夠不夠用:
窄韻(如二冬、三江)可用字少,寫長了會被逼出韻。

**對仗在律詩的中間兩聯。** 詞性相對、結構相稱,而**同一個位置不得用同一個字**。
首聯尾聯不要求對仗。

**拗救是合法的。** 「平平仄平仄」這類特拗格式在傳世詩裡到處都是
(如張說〈經鄒魯祭孔子而歎之〉的「今看兩楹奠」)。lint 因此**只查第二字**的平仄相對,
不查四六——那條邊界是拿 219 首傳世近體詩量出來的,不是憑感覺定的。

## 成語運用

近體詩**不用成語**。五七言的字數不容許四字現成語塞進去而不擠掉意象;
真正的做法是用典——把典故壓縮成兩三個字,讓讀的人自己展開。
「莊生曉夢迷蝴蝶」七個字裡有一個完整的典,那不是成語。

## 跑 lint

```
python3 scripts/verse_check.py 你的詩.md
```

判這些:

- 句數 4 或 8、每句五言或七言、全篇字數一致
- 韻腳落在**同一個平水韻部**(只認詩韻正文,不認【詞】【辭】補充字)
- 韻腳不得重複用同一個字
- 對句**第二字**平仄相對
- 律詩頷聯頸聯**同位不得重字**

## ⚠ 明標不判的部分

| 不判 | 為什麼 |
|---|---|
| **黏**(下聯出句與上聯對句的平仄相承) | 拗體變化多,誤判成本高於漏判 |
| **拗救** | 合法變格眾多,規則化會誤殺傳世詩 |
| **對仗的詞性與語義相對** | 需要斷詞與語義類別標註,錯誤的斷詞會誤殺 |
| **意境、用典是否貼切** | 沒有機器真相 |
| **兩讀字的語境消歧** | 872 字同時見於平仄兩部,字級判不了;lint 採「任一讀音合律即過」,寧漏報不誤報 |
| **表外字** | 平水韻收 8,550 字,表外字的韻與平仄一律列「未驗到」,不當通過也不當違規 |

「未驗到」會印出來,**不會被吞掉**——判定不出來不等於沒問題。

## 這個 repo 裡有 lint 的文體

見 `docs/genres.md`。

**不要拿 `poetry` 的規則套這一支**:那支是現代詩/新詩,核心手法之一是「打破常規語法」,
與格律的定句定字正面衝突。同理,不要拿本支去量新詩。
