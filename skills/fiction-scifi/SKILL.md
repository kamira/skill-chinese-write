# fiction-scifi — 科幻小說

> 這是 **`fiction` 主層的子層**。主層管小說怎麼被讀進去(對話、分段、分章),本支管這個流派怎麼寫。

## 篇幅

不限篇幅

## 怎麼寫

以科學理論或未來想像為基礎,**探討技術對人性的衝擊**,建立理性的世界觀。

文字偏向**冷峻、客觀**,多用**類比**(把新概念接到讀者已知的東西上)與**陌生化描寫**(把熟悉的東西寫得像第一次看見)。

## 兩個配比

| | 數值 | 誰在管 |
|---|---|---|
| **修辭比例** | 低(10%-15%) | **靠人判斷**——沒有程式量得出一段文字有幾成是譬喻 |
| **成語密度** | 1-3 次/千字(**過多古典成語會直接破壞未來感**) | lint 會數(`--genre scifi`),但區間是本 skill 自訂,不是原始規格的百分比 |

## 成語落在哪裡

**僅在主角直面「超越人類現有認知、極度震撼的宇宙奇觀或巨型結構」時**,用來形容其精神狀態。

其餘一律不用。古典成語帶著它自己的時代,放進未來場景會把讀者拉回過去——這是這個流派最貴的一種出戲。

**落腳段落**:【宇宙 / 高科技造物初次登場的震撼描寫段】

## 主層的硬規範一樣要遵守

換人說話就獨立成段(同段最多兩處引號)、段落字數上限(實體 150 字 / 網文 80 字且不超過 3 行)、擬聲詞不用「X!」一聲的樣板、章節字數區間。細節見 `fiction` 的 [`references/dialogue.md`](../fiction/references/dialogue.md) 與 [`references/structure.md`](../fiction/references/structure.md)。

## 這個流派靠你自己判斷的

- **設定自洽嗎**。程式判不了你的物理規則有沒有互相打架。
- **技術對人性的衝擊寫出來了嗎**。這是科幻與「有太空船的冒險故事」的分界,而它沒有任何字面特徵。
- **切章點**(斷頭台法則)。lint 量得出章有多長,量不出你停在哪一秒。

## 交稿前跑 lint

lint 在主層,本支不另外寫一份——武俠與科幻的規則檔會有 95% 相同,而重複的規則檔一定會分岔。安裝本 plugin 時主層會一起帶進來。

```
python3 skills/fiction/scripts/fiction_check.py 稿件.md --genre scifi
```

網路連載加 `--mode web`(段落上限收緊為 80 字且不超過 3 行)。
