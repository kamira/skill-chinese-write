# fiction-flash — 微型小說(極短篇 / 掌篇)

> 這是 **`fiction` 主層的子層**。主層管小說怎麼被讀進去(對話、分段、分章),本支管這個流派怎麼寫。

## 篇幅

數百至兩千字

## 怎麼寫

結構極度緊湊,**省去繁複背景,直接切入核心衝突**。追求出人意料的結尾反轉。

字數珍貴到每一個詞都要付租金,所以多用**象徵**與**留白**——用一個物件承載整段沒寫出來的關係,比解釋那段關係省一百個字。

## 兩個配比

| | 數值 | 誰在管 |
|---|---|---|
| **修辭比例** | 低至中(15%-20%) | **靠人判斷**——沒有程式量得出一段文字有幾成是譬喻 |
| **成語密度** | 1-3 次/千字(全流派最低之一) | lint 會數(`--genre flash`),但區間是本 skill 自訂,不是原始規格的百分比 |

## 成語落在哪裡

只有在故事收束、需要「一筆定乾坤」時才借用成語的爆發力。

其餘位置一律不用:成語是別人用過的畫面,而微型小說唯一的資產就是細節的獨特性。

**落腳段落**:最後一行的【結局反轉 / 戛然而止段】

## 主層的硬規範一樣要遵守

換人說話就獨立成段(同段最多兩處引號)、段落字數上限(實體 150 字 / 網文 80 字且不超過 3 行)、擬聲詞不用「X!」一聲的樣板、章節字數區間。細節見 `fiction` 的 [`references/dialogue.md`](../fiction/references/dialogue.md) 與 [`references/structure.md`](../fiction/references/structure.md)。

## 這個流派靠你自己判斷的

- **反轉夠不夠意外**。這是這個文體的全部,而且完全判不了。
- **留白留在對的地方**。省掉背景是技巧,省掉讀者需要的線索是失誤,差別只有讀的人知道。
- **切章點**(斷頭台法則)。lint 量得出章有多長,量不出你停在哪一秒。

## 交稿前跑 lint

lint 在主層,本支不另外寫一份——武俠與科幻的規則檔會有 95% 相同,而重複的規則檔一定會分岔。安裝本 plugin 時主層會一起帶進來。

```
python3 skills/fiction/scripts/fiction_check.py 稿件.md --genre flash
```

網路連載加 `--mode web`(段落上限收緊為 80 字且不超過 3 行)。
