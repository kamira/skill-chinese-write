# 聲音與節奏

> 這份管「怎麼講」;骨架看 [`commentary.md`](commentary.md),清詞看 [`ai-tells.md`](ai-tells.md)。
> 本檔所有數字門檻的單一真相在 [`../assets/style_rules.json`](../assets/style_rules.json),由 `scripts/style_check.py` 執行。

## 第一人稱:站出來

用「我」。這不是風格偏好,是責任歸屬——評論的重量來自有人願意具名承擔一個判斷。

要清掉的替身:

| 別寫 | 改成 |
|------|------|
| 筆者認為 | 我認為 / 我覺得 / 直接講判斷,不用「我認為」也行 |
| 本文將探討 | (整句刪掉) |
| 我們可以看到 | 我看到 / 你會發現 |
| 不難發現 | (整句刪掉,直接講發現了什麼) |
| 可以說 | (刪掉) |
| 讓我們一起來 | (刪掉) |

「我」不必每段都出現,但**開頭兩百字內一定要出現一次**,讓讀者知道現在誰在講話。之後可以退到背景,讓事實自己講,需要下判斷時再回來。

還有一件事:「我認為」不要當口頭禪。整篇每個判斷都掛「我認為」,反而顯得心虛。判斷句直接講,那本來就是你的判斷:

> ✗ 我認為這個決定是錯的,我覺得它會在兩年內反噬。
> ✓ 這個決定是錯的。它會在兩年內反噬。

## 口語:唸得出來

唯一的檢驗方式是**唸出聲**。唸起來卡、唸起來像在唸文件,就重寫。

具體怎麼換:

| 書面腔 | 口語 |
|--------|------|
| 進行了深入的探討 | 好好聊了一下 / 談得很深 |
| 具有相當程度的影響 | 影響不小 |
| 就目前而言 | 現在 |
| 在此情況下 | 這樣一來 / 這時候 |
| 呈現出下降趨勢 | 一直在掉 |
| 予以考量 | 想一下 / 納進來想 |
| 係屬 | 是 |

口語不等於隨便。它的意思是:**用你跟朋友解釋這件事時會用的詞,但把話講得比平常更準**。可以有語氣(「說真的」「老實講」「這就有點怪了」),但一段一個就夠,多了變油。

括號和破折號是口語的好工具——它們是側身講一句話。但破折號有配額(每千字四個以內),超過就變成你不會用句號。

## 節奏:句長要參差

最容易露餡的地方。AI 寫的中文有一個共同特徵:**每句都差不多長**,十五到二十字,一路平到底。讀起來像節拍器。

看差別:

> ✗ 這項政策的推行帶來了不小的爭議,支持者認為它能有效改善現況,反對者則擔心執行層面會出現問題,雙方各執一詞難有交集。
>
> ✓ 這政策一出來就吵翻了。支持的人說它有用。反對的人說根本執行不了,基層會被壓死,而且壓死的方式在兩年前那次類似的改動裡已經演過一次,只是那次沒人記得。誰對?我看兩邊都沒講到重點。

第二段的句長是:11 / 8 / 43 / 2 / 10。這才是人講話的樣子。

三條操作規則:

1. **長句之後接短句。**寫完一個三十字以上的長句,下一句給七八個字。落差製造重音。
2. **全篇至少要有一句短到不能再短的。**八個字以內。放在你要讀者停一下的地方。
3. **不要連續三句字數差不多。**lint 會抓:連續三句彼此相差兩字以內就標記。

量化門檻:句長**變異係數(CV)低於 0.35** 就是節奏平板,lint 會警告。健康的評論文章通常落在 0.45 到 0.8。

## 刻意句:偶爾可以,不是常態

「刻意句」指你為了效果特別雕過的句子。三種形態:

| 形態 | 樣子 |
|------|------|
| **字數對稱** | 省下的是租金,賠掉的是接班。 |
| **工整反差** | 它擋得住掩體,擋不住躲在後面的那個人。 |
| **明喻** | 它像戒菸貼片,治不了想抽的念頭。 |

規則是**配額**,不是禁止:

- 三種合計,全篇最多 **3 處**。
- 兩處之間至少隔 **3 句**,不准連用。
- 落在**段末**的最多 **2 處**。每段都用一句金句收尾,讀起來就是在擺姿勢。
- 放的位置只有兩種:段落的最後一句(收力),或一個轉折的支點(翻面)。

隱喻(「抽象詞是掩體」這種不帶「像」的)不計入。它跟一般敘述沒辦法用機器分開,只能自己拿捏——但同一套道理適用:偶爾一個很好,滿篇都是就變成在演講。

用對的樣子:

> 省下的是租金,賠掉的是接班。

六字對六字,結構呼應,砸在段末。整篇有這麼一句,讀者會記住它。

用錯的樣子:

> ✗ 制度需要調整,執行需要落實。溝通需要加強,共識需要凝聚。文化需要建立,信任需要累積。

三組對稱連著砸,變成標語牆。而且沒有一句有具體內容——這是對稱句最大的危險:**它太順了,順到你會忘記檢查裡面有沒有東西**。

寫完一個刻意句,問自己:如果拆成平話,還講得出一樣多的資訊嗎?講不出來,代表你為了句型砍掉了內容,那就別雕。

### 一個已知代價

拿這支 skill 寫的文章丟 GPTZero,被判「最像 AI」的句子清一色是刻意句——明喻、工整反差、段末斷語。它給的理由是缺少修辭裝飾、語法太標準、描述太精確。反過來,它判「最像人」的是帶情緒的比喻、口語提問、以及「我讀完它們才動手」這種第一人稱的動作句。

這件事有兩層意思,分開看:

**第一層**:雕過的句子確實是 LLM 潤稿最愛的音色,少用有道理。上面的配額就是為此收緊的。

**第二層**:那些偵測器獎勵的東西——華麗的修辭、不標準的語序、迂迴的表達——**跟本 skill 的主張正面相反**。這裡教的是刪掉裝飾、動詞直接用、話講清楚。清楚的散文本來就會被判得像機器,這是清楚的代價,不是缺陷。

所以:**不要為了分數改寫**。偵測器換一版,判準就換一套;把文章往華麗那邊推,換來的是另一種毛病。配額照守,理由是節奏跟誠意,不是分數。

## 段落

段落長度也要參差,道理跟句子一樣。句子參差但每段一樣重,讀起來還是平的——這是最常被漏掉的一層。

- 不要每段都五到六行。中間插一個一到兩行的短段。
- 一個段落一個意思。意思轉了就換段,不要因為「這段太短了」硬塞。
- **允許一句話自成一段。**用在你要它被看見的時候。但一篇最多兩三次,不然就變成排版特技。

量化門檻(lint 會抓):實質段落有 **4 段以上**時,若全部擠在 **25 字以內的區間**,判「每段一樣重」;沒擠在一起但**段長變異係數低於 0.25**,判「節奏偏平」。

排段落的輕重,想成:短拍 → 中段 → 厚段 → 短落地。不必照這個順序,但一篇裡要有輕重。

## 排版節制

評論是散文,不是投影片。

- **不分節的評論:條列能不用就不用。**論證本身用文字推,不要拆成清單。
- **議題型的現象節:可以條列**,而且該條列。每項只放扼要重點,上限 **16 字**,完整說明寫進段落——細節見 [`commentary.md`](commentary.md) 的議題型節。
- lint 會算條列行佔比,超過 **25%** 警告。條列本身**不進**句子層級的統計(節奏、對稱句、刻意句、粗體上限都跳過它)——條列本來就短而齊,拿散文標準去量必然誤報。
- 粗體是重音,不是螢光筆。一段最多一處。整段粗體等於整段沒重點。
- 小標可以有,但小標不該是「一、背景」「二、分析」「三、結論」這種。小標本身就要有內容,最好本身就是一個判斷。lint 收了一份結構標籤清單(前言/背景/分析/結論/總結/概述/簡介/反觀/省思/引言/小結),命中就警告;議題型的 `現象`/`結語`/`後記` 是功能名,放行。
- 標題不計入句長統計。「現象」兩個字不是一個 2 字的句子,把它算進去只會扭曲節奏數據。
